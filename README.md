*Améliore les items de display avec une boutique et un système de collections.*

## Présentation

Améliore les items de display avec une boutique et un système de collections.

Utilisé sur : **Opale**.

## Dépendances

- Optionnelles : `PlaceholderAPI`, `Vault`

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/deco` | `/decorations` | Ouvre le menu principal des collections et de la boutique. | — |
| `/shdeco` | `/shdisplay` | Commande d'administration pour SHDisplayEnhanced. | `shdisplayenhanced.admin` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shdisplayenhanced.user` | Permet d'utiliser la commande /deco. | `true` |
| `shdisplayenhanced.admin` | Permet d'utiliser les commandes d'administration. | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `config.yml`
- `shop.yml`

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
